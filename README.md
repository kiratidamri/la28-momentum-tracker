# LA28 Momentum Tracker

**Team USA Olympic & Paralympic Analytics Platform**

An AI-powered web application that tracks Team USA's competitive momentum across 18 Olympic and Paralympic disciplines ahead of the Los Angeles 2028 Games. Built with Gemini 2.5 Flash and deployed on Google Cloud Run.

🔗 **[Live Demo](https://la28-momentum-tracker-1069330341609.us-central1.run.app)**

---

## What It Does

The app rates each Team USA sport on a **momentum score from 0–100**, generated by Gemini 2.5 Flash based on recent competitive performance, athlete trajectories, and medal prospects. Two modules:

**Momentum Dashboard** — ranks all 18 sports in real time with AI-generated scores and insights. Falls back to hardcoded baseline data if the API is unavailable, so the product is always live.

**AI Analyst Chatbot** — an interactive assistant with deep knowledge of both Olympic and Paralympic athlete narratives. Ask about medal forecasts, athlete comparisons, or sport-by-sport breakdowns.

## Setup

**Prerequisites:** Python 3.11+, a Google AI Studio API key

```bash
git clone https://github.com/kiratidamri/la28-momentum-tracker.git
cd la28-momentum-tracker
pip install -r requirements.txt
```

Create a `.env` file:

```
GEMINI_API_KEY=your_api_key_here
```

Run locally:

```bash
python app.py
```

Open `http://localhost:5000`

---

## Deploy to Google Cloud Run

```bash
gcloud run deploy la28-momentum-tracker \
  --source . \
  --region us-central1 \
  --allow-unauthenticated \
  --set-env-vars GEMINI_API_KEY=your_key_here
```
